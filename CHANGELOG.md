# Changelog

## 0.1.0 — 2026-10-29

First release, extracted from the DeutschUz data pipeline.

- Latin → Cyrillic (1956 orthography) and Cyrillic → Latin (1995 orthography)
- 728 loanword stems with Uzbek suffix matching
- Foreign words, abbreviations, IPA and apostrophe normalization
- Command line tool `uzcyrl`
